# 浮点数类型

## 什么是浮点数类型

> 简单的来说，就是用于存放小数值的，比如3.14,0.28,-0.79

## 浮点类型种类

| 类型    | 存储空间 | 表数范围 |
| ------- | -------- | -------- |
| float32 | 4字节    |          |
| float64 | 8字节    |          |



```go
package main

import "fmt"

func main() {
	//定义浮点类型的数据
	var num1 float32 = 3.14
	fmt.Println(num1)
	//可以表示正浮点数，也可以表示负的浮点数
	var num2 float32 = -3.14
	fmt.Println(num2)
	//浮点数可以用十进制表示，也可以用科学记数法表示形式，E大写小写都是可以的
	var num3 float32 = 314e-2
	fmt.Println(num3)
	var num4 float32 = 3.14e-2
	fmt.Println(num4)
	var num5 float32 = 3.14e+2
	fmt.Println(num5)
	var num6 float64 = 3.14e+2
	fmt.Println(num6)

	//浮点数可能有精度的缺失，所以通常情况下，建议使用： float64
	var num7 float32 = 256.000000000014
	fmt.Println(num7)
	var num8 float64 = 256.000000000014
	fmt.Println(num8)

	//Go中默认的浮点类型为： float64
	var num9 = 3.17
	fmt.Println("num9对应的数据类型为： %T", num9)

}

```

# 字符类型

1. Golang中没有专门的字符类型，如果要存储单个字符（字母），一般使用byte来保存
2. Glang中字符使用UTF-8编码
3. ASCLL码表

```go
package main

import "fmt"

func main() {
	//定义字符类型的数据
	var c1 byte = 'a'
	fmt.Println(c1) //97
	var c2 byte = 'b'
	fmt.Println(c2) //98
	var c3 byte = 'c'
	fmt.Println(c3) //99
	//字符类型本质上是一个整数，也可以直接参与运算，输出字符的时候，会将对应的码值做一个输出
	//字母，数字，标点等字符，底层是按照ASCII进行存储

	var c4 int = '中'
	fmt.Println(c4)
	//汉字字符，底层对应的是Unicode码值
	//对应的码值为20013,byte溢出，能存储的范围可以用int
	// 总结： Golang的字符对应使用的是UTF-8编码(Unicode是对应的字符集，UTF-8是unicode的其中一种编码方案

	var c5 byte = 'A'
	//要想显示出对应的字符，必须采用格式化输出
	fmt.Printf("c5对应的字符为：%c", c5)
}

```

# 布尔类型

1. 布尔类型也叫做bool类型，bool类型数据只允许取值true与false
2. 布尔类型只占据1个字节
3. 布尔类型适合逻辑运算，一般用于程序流程控制

```go
package main

import "fmt"

func main() {
	// 测试布尔类型的数值
	var flag01 bool = true
	fmt.Println(flag01)

	var flag02 bool = false
	fmt.Println(flag02)

	var flag03 bool = 5 < 9
	fmt.Println(flag03)
}
```

```go
		"abc" + "def" + "abc" + "def" + "abc" + "def" + "abc" + "def" +
		"abc" + "def" + "abc" + "def" + "abc" + "def" + "abc" + "def" +
		"abc" + "def"

}
```
