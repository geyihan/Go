2. 学习完成后可以使用官Goland
3. 多敲命令
4. 每日笔记上传到Github

## 01-安装Go环境

### mac

在终端里面安装

```sh
brew install go
```

安装完成检查命令如下

```sh
❯ go version
go version go1.27.3 darwin/arm64
```
